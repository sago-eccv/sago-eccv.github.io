# SAGO · ECCV 2026

Project website for **Online Segment 3D Gaussians via Launching Virtual Drones** by Liwei Liao, Rongjie Wang, and Ronggang Wang.

- Website: https://sago-eccv.github.io/
- Research code: https://github.com/leviome/SAGO

Dependency-free static website, served by GitHub Pages from `main` at the repository root. Preview with `python3 -m http.server 8765` in this directory, then open http://localhost:8765.

`index.html`, `styles.css`, and `script.js` contain the page, responsive styling, and optional citation-copy enhancement. `assets/` includes the camera-ready paper, supplementary PDF, poster, SAGO demonstration videos, and figures rendered from the paper. Original research sources remain unchanged.

Layout inspired by [TRACE-3D](https://trace-3d.github.io/) and [Nerfies](https://nerfies.github.io/). The implementation is original; no TRACE-3D research text or media is included. Research content and media belong to the SAGO authors. See the research repository for its code license.
